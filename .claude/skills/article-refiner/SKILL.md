# 审阅与修改文章

1. 按[仓库指南](../../../AGENTS.md)读取目标文章全文、front matter、脚注及关联资源，标出需要保留的作者判断、稳定锚点和原始数据。只要求审阅时，报告可定位的问题。
2. 遇到图片写法、带语言的围栏和 shortcode，先按[本站内容语法](../../../docs/hugo-content.md)识别其输出。检查标题末尾的属性、外部代码的行范围，以及示例中 shortcode 是否有意转义。保留能复用的源文件和图表配置。
3. 先处理影响结论的事实或推导，再按用户范围调整结构和措辞。以最新稿为准，用户删掉的解释只有在能指出具体断点时才补回。
4. 对照 diff 核对数据、引用和作者语气。修改嵌入内容时，检查目标页面实际显示的片段、图形或横幅。运行与改动相符的 Hugo、Markdown 和渲染验证。
